# Hey, I'm Leo 👋

I'm a 14 y/o developer building open-source and open-core tools around AI agents, developer workflows, SDKs, CLIs, and local-first software.

Most of my public work happens through [OpenCore](https://github.com/opencoredev), an organization I use for the projects I want to keep building in the open.
